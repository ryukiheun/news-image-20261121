A program that ships a 1024x1024 newspaper-style front page summing up Saturday 21 November 2026 in six stories — Iran saying it hit US positions in Bahrain, Mexico's capture of one of the FBI's 10 most wanted cartel bosses, "El Chapo Isidro", the certification of a claimed Riemann hypothesis proof, Max Verstappen's Las Vegas Grand Prix win, KL Rahul's 136 putting India ahead on Day 3 in Wellington, and Cyclone Akvan fading with no lives lost. The PNG is drawn by render.py during the build and committed as entry.png; `Run it` below only copies that committed PNG to the output directory (main.py; /output by default). If entry.png is missing, main.py fails with a file-not-found error; it creates the output directory if needed and touches nothing else.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out python3 main.py
```
